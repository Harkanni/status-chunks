# Status Splitter Landing Page

A responsive React/Vite landing page for Status Splitter.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production files are generated in `dist/`.

## Use your existing app

Replace `appUrl` in `src/main.jsx` with the route/URL where your existing Status Splitter tool lives.

The product screenshot is in `src/assets/status-splitter.png`.
